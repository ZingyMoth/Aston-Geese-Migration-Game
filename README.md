# Aston Geese Migration Game
A game I created for my Computer Science module at Aston University. The player controls a goose and must navigate through a series of obstacles to reach its destination.

## Built With
* Java
* Processing

## How to Run
1. Download and install Processing from processing.org
2. Download this repository by clicking Code and then Download ZIP
3. Extract the ZIP file
4. Open the Aston_Geese_Migration_Game_V22_Completed folder
5. Open the .pde file in Processing
6. Press Run to start the game

## About
This project was my first game built in Java. It helped me learn the fundamentals of object oriented programming, game loops, user input and collision detection.
